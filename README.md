# 随身下载插件源

这里是「随身下载」应用的插件源，只包含插件脚本，不包含应用本身。

## 使用方法

在应用里打开 **插件 → 在线插件 → 添加插件源**，填入下面的地址：

```
https://raw.githubusercontent.com/whykang/ssxz/main/index.json
```

添加后可以看到源里的全部插件，并在那里安装和更新。

## 插件列表

| 插件 | 版本 | 说明 |
|---|---|---|
| 必应壁纸 | 1.0 | 搜索并下载必应每日壁纸（最近约 15 天），输入“最新”查看全部 |
| 网盘解析 | 1.6 | 解析蓝奏云、夸克网盘、百度网盘的分享链接（支持文件夹和提取码），取出文件并下载 |
| 短视频聚合解析 | 1.2 | 粘贴分享内容，解析并下载抖音、快手、小红书、B站、微博等平台的视频或图文 |
| 网页视频嗅探 | 2.0 | 粘贴网页地址，在应用里打开网页并自动嗅探视频和音频，支持 m3u8 |

## 编写插件

插件是一个 JavaScript 文件，接口和插件源的格式见 [插件开发说明](插件开发说明.md)。

## 说明

插件只负责解析公开页面或调用第三方接口，不破解加密或付费内容。请遵守相关网站的使用条款和当地法律，下载的内容仅供个人使用。
